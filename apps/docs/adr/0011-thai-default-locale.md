# 0011 · ไทยเป็น default locale

<Status value="in-progress" note="apps/web ยังเป็น en" />

- **สถานะ:** accepted
- **วันที่:** 2026-08-07
- **หมวด:** i18n

## บริบท

ผู้ใช้หลักของผลิตภัณฑ์นี้เป็นคนไทย แต่ `apps/web/src/i18n/routing.ts` ตั้ง `defaultLocale: "en"` ซึ่งเป็นค่าที่ติดมาจากตอน scaffold ไม่ใช่การตัดสินใจ ขณะเดียวกันเอกสารชุดนี้ตั้งใจให้ไทยเป็นภาษาหลัก การปล่อยให้สองที่ไม่ตรงกันจะทำให้เกิดความสับสนไปเรื่อย ๆ

## การตัดสินใจ

**ภาษาไทยเป็น default locale ทั้งผลิตภัณฑ์และเอกสาร**

| | default | ภาษาที่สอง |
| --- | --- | --- |
| `apps/web` | `th` (จะแก้) | `en` |
| `apps/docs` | `th` (root) | `en` (`/en/`) |

- ข้อความที่ผู้ใช้เห็นเขียนภาษาไทยก่อน แล้วแปลเป็นอังกฤษ
- **โค้ด คอมเมนต์ ชื่อตัวแปร ข้อความ commit เป็นภาษาอังกฤษเสมอ**
- ศัพท์เทคนิคคงเป็นอังกฤษในเนื้อความไทย (trace id, ability, envelope, contract) ไม่แปลทับศัพท์แบบฝืน ๆ
- `message` ใน error envelope เป็นอังกฤษเสมอ (สำหรับนักพัฒนา) ส่วนผู้ใช้เห็นข้อความที่แปลจาก `code`

## ทางเลือกที่พิจารณา

### อังกฤษเป็น default ทั้งคู่
เป็นค่าปกติของโปรเจกต์ open source และทำให้คนนอกอ่านได้ทันที แต่ผู้ใช้จริงเป็นคนไทย การให้ภาษาหลักของผู้ใช้เป็นพลเมืองชั้นสองแปลว่าข้อความไทยจะแปลตามอังกฤษเสมอ ซึ่งมักได้ภาษาที่อ่านแล้วรู้ว่าแปลมา

### ไทยอย่างเดียว ไม่มีอังกฤษ
maintain ง่ายที่สุด แต่ปิดทางไม่ให้คนที่ไม่อ่านไทยเข้ามาช่วย และตัดความเป็นไปได้ที่จะเปิดผลิตภัณฑ์ให้ผู้ใช้ต่างชาติ

### ไทยเป็น default ของ web แต่อังกฤษเป็น default ของ docs
ลดภาระการแปลเอกสาร แต่สร้างความไม่สอดคล้องที่ต้องอธิบายทุกครั้ง และคนที่เขียนเอกสารคือคนเดียวกับที่เขียนผลิตภัณฑ์

## ผลที่ตามมา

**ได้:** ผู้ใช้เห็นภาษาแม่โดยไม่ต้องกด · ข้อความไทยเป็นต้นฉบับจึงเป็นธรรมชาติ ไม่ใช่คำแปล · เอกสารกับผลิตภัณฑ์ตั้งค่าเหมือนกัน อธิบายง่าย

**เสีย:** ทุกอย่างที่ผู้ใช้เห็นต้องเขียนสองภาษา · local search ของ VitePress ต้องใช้ตัวตัดคำไทย (`Intl.Segmenter`) เพราะภาษาไทยไม่เว้นวรรค · คนที่มาช่วยแต่ไม่อ่านไทยจะเริ่มยากกว่า

**ต้องทำต่อ:** แก้ `apps/web/src/i18n/routing.ts` เป็น `defaultLocale: "th"` · ตรวจว่า `localePrefix` ทำงานตามที่คาด · เขียน `apps/web/messages/th.json` ให้เป็นต้นฉบับ แล้ว `en.json` เป็นคำแปล

::: warning สถานะโค้ดปัจจุบัน
| สเปกเป้าหมาย | โค้ดวันนี้ |
| --- | --- |
| `defaultLocale: "th"` | `apps/web/src/i18n/routing.ts` ยังเป็น `"en"` |
| ไทยเป็นภาษาต้นฉบับของข้อความ | `messages/{th,en}.json` มีแค่ namespace `HomePage` |
| มีตัวสลับภาษาบน UI | ไม่มี component นี้ |
:::
